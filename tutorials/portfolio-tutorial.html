How to create a portfolio website

A simple tutorial to create a portfolio website using HTML, CSS, and GitHub Pages.

By Caroline Heijmans

On this page

Step 0: Set upStep 1: BrainstormStep 2: MockupStep 3: BuildStep 4: ReviewStep 5: Add filesStep 6: Publish

Goal

This tutorial will show you how to build a simple portfolio website from scratch using HTML, CSS, and free tools. You could also use a tool like Canva to create your portfolio, but coding it yourself gives you more flexibility to customize the design and choose what to include.

Along the way, you’ll get an introduction to the basics of web development. You don’t need any coding experience to follow along: you’ll learn as you go, with AI to help you through the more advanced parts.

This tutorial keeps things simple and assumes you’re already somewhat familiar with:

  • Using OpenCode with a free AI model
  • Using VS Code
  • The basics of HTML and CSS
  • Hosting a website on GitHub Pages

If any of this is new to you, don’t let that stop you! There are plenty of tutorials to help you get started and learn as you go.

Step 0: Set up your tools

  • OpenCode and a free AI model
  • VS Code
  • Canva
  • Pinterest
  • GitHub

You will need a few tools to get started. All of them are free and will only require you to create a free account. If you’re unfamiliar with these tools, don’t let that stop you. They are quite user-friendly, and there is plenty of documentation to help you get started with them.

Step 1: Brainstorm with Pinterest

Before you start, take some time to think about what you want to include in your portfolio. Which projects will you showcase? How many pages will you need?

Then, think about the style. Browse Pinterest or any other source of inspiration you enjoy. This is usually where I find my initial ideas.

Step 2: Create a mockup in Canva

I like to use Canva to create a mockup, but paper and pencils work too. The aim is to plan what your website will look like before you start building it.

Canva makes it easy to explore fonts, icons, and colors that you can later use on your website. I find it easier to test different combinations there before moving on to development.

Step 3: Create your website locally

This is where things get a little more technical. Create a folder on your laptop and open it in VS Code. Inside that folder, create a file called AGENTS.md. This file gives your AI coding agent instructions about the website you want to build.

Use the template below as a starting point and adapt it to your project. Include any specific fonts or colors you want to use, either in AGENTS.md or in your prompt. Keep the styling simple at first: one font for headings and one for paragraphs may be enough.

# Portfolio build specification

## Goal
Create a personal portfolio for [name / discipline].
Audience: [clients / employers / collaborators].
Use the supplied mockup as a visual reference.

## Technology
- Plain HTML and CSS. JavaScript only if needed for interaction.
- No frameworks, package dependencies or build step.
- Must open locally and work on GitHub Pages.

## Content and files
- index.html: intro, work, about and contact sections.
- styles.css: shared styles for every page.
- assets/images/: project images.
- assets/files/: public PDFs or other downloads.
- Optional project pages: project-name.html.
- Use the content I provide; mark missing text as placeholders.
- Do not invent experience, clients or results.

## Design
- Style: [minimal / editorial / desktop-inspired].
- Colors: [background, text and optional accent].
- Fonts: [system fonts or licensed font files I supply].
- Define colors, fonts and spacing as CSS variables in :root.
- Reuse classes; keep all website styling in styles.css.

## Quality
- Responsive layout for phone and desktop; no page overflow.
- Semantic HTML, logical headings and descriptive image alt text.
- Keyboard-accessible links and visible focus styles.
- Respect prefers-reduced-motion if adding animation.
- Relative paths, e.g. assets/images/project-one.jpg.
- No secrets, private files or non-working contact forms.
- Explain how to preview the site and what each file does.

Once your AGENTS.md file is ready, open the project in OpenCode, attach a screenshot of your Canva mockup, and write a prompt such as: “Create the homepage and the following pages: [list your pages]. Use the attached screenshot as a reference.”

If your pages have very different layouts, it may be easier to build them one at a time. Start with the homepage, then move on to the others.

Step 4: Review and make small changes

Now it’s time to take a closer look at your HTML and CSS files.

The CSS file controls how your website looks, including the styling of buttons and headings. Keeping shared styles in one place makes it easier to make changes across the whole website.

The HTML files define the content and structure. In this project, each HTML file represents a page, so this is where you can edit your text.

If you’re unsure what you’re looking at, ask your AI coding agent. Try questions like, “How do I change this heading?” or “What does this part of the code do?” I recommend using AI to help you understand the code as you make changes. Sometimes, knowing what to edit yourself is quicker than explaining every change you want the agent to make, which is why it’s nice to know the basics of coding.

Step 5: Add your files

If you haven’t already, add the files you want to display, such as images of your work, to the appropriate folder in your project. Your project folder could look like this:

my-portfolio/
├── index.html
├── styles.css
├── AGENTS.md
└── assets/
    ├── images/
    │   └── project-one.jpg
    └── files/
        └── portfolio.pdf

Step 6: Publish with GitHub Pages

On GitHub, choose New repository, name it portfolio, and select Public. Leave the README, license, and .gitignore options unselected, then create the repository.

Next, upload your website files to GitHub. In VS Code, open a new terminal in your my-portfolio folder. Run the commands below one line at a time in that terminal, rather than inside OpenCode. Replace YOUR-USERNAME with your GitHub username.

git init
git branch -M main
git add index.html styles.css assets/
git status
git commit -m "Create portfolio website"
git remote add origin https://github.com/YOUR-USERNAME/portfolio.git
git push -u origin main

Once your files are uploaded, publish your website:

  1. Open your repository on GitHub and go to Settings → Pages.
  2. Under Build and deployment → Source, choose Deploy from a branch.
  3. Select main and /(root), then click Save.
  4. Wait for deployment to finish. Your website’s URL will appear on the Pages screen. You can also follow the deployment progress in Actions.
